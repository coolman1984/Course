## دروس بتتكرر في كل أداة

١. **الـ DRM بيحدد مين يفتح الملف.** على لابتوب عليه NASCA، ملف الإكسل أو الوورد متشفّر على الديسك، وأي برنامج غير الأوفيس بيشوفه كلام ملخبط. علشان كده الأداة بتخلّي إكسل ووورد يقروا الملفات بطريقة COM، وPowerShell يكتب القيم في CSV عادي. ولو Python قال إن الملف «مش ملف عادي»، شغّل الأداة كلها من Run_Tool.bat بدل ما تشغّل خطوة Python لوحدها.
٢. **الباكدجات ممنوعة، والمكتبة القياسية كفاية.** قراءة xlsx وdocx بـ zipfile وxml.etree، والـ PDF بـ re وzlib، والحساب بقاموس بيجمع، وقاعدة البيانات بـ sqlite3. مفيش pip install في أي خطوة.
٣. **فولدر Data للقراءة بس.** كل ملف بيتفتح ReadOnly، وكل النتايج بتروح Output. ولو فيه نتيجة قديمة، بتتنقل لـ Output\Previous ومش بتتمسح.
٤. **إكسل لازم يتقفل حتى لو حصل خطأ.** كل سكريبت فيه finally بيقفل الملف ويقفل إكسل ويحرّر الـ COM. بعد التشغيل افتح Task Manager: مش المفروض تلاقي EXCEL.EXE.
٥. **قراءة الشيت مرة واحدة، وكتابته مرة واحدة.** القراءة خانة خانة عن طريق COM بطيئة جدًا. الأداة بتقرا UsedRange.Value2 كله في مرة، وبتكتب الجدول كله في مرة.
٦. **التواريخ بتيجي أرقام.** ‏Value2 بيرجّع التاريخ كرقم يوم في إكسل (زي 46204)، والأداة بتحوّله لشكل yyyy-mm-dd.
٧. **النص اللي شبه التاريخ لازم يتحمي.** الشهر «2026-07» لو اتكتب في خانة عادية، إكسل ممكن يقلبه تاريخ. علشان كده العمود بيتعمل Text الأول.
٨. **كل خطوة بتراجع نفسها.** عدد الصفوف والإجمالي قصاد ملفات المصدر، و‎#N/A لازم صفر، والإجمالي في الجدول المحوري لازم يساوي الجدول. ولو رقم واحد اختلف، الأداة بتوقف برسالة واضحة.
٩. **سياسة التشغيل.** ملف Run_Tool.bat بيشغّل PowerShell بـ ‎-ExecutionPolicy Bypass للأداة دي بس. ولو قسم الـ IT قافل ده بسياسة على الجهاز، الأداة مش هتشتغل: اطلب منهم يسمحوا بالفولدر ده، وما تحاولش تتخطّى السياسة بأي طريقة.
١٠. **Python مش موجود؟** الأداة بتدوّر على python وعلى py، وبتتجاهل اختصار Microsoft Store. لو مش موجود، اطلب النسخة المعتمدة من الـ IT، وما تنزّلش حاجة بنفسك.
