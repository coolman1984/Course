The ready tool - unit 3, example 1: the production dashboard
============================================================

One click:
1. Unzip into a folder of its own, and keep the Data and Ready_Tool folders side by side as they are.
2. Open the Ready_Tool folder and double-click Run_Tool.bat.
3. Each step writes what it did. At the end you must see the line ALL STEPS PASSED, and the dashboard opens by itself.

What appears in the Output folder:
- Production_Q3_Dashboard.xlsx: the Dashboard, the Report, the pivot tables (Pivots) and the Data with two VLOOKUP columns.
- Check_Report.txt: the figures that must come out; compare them with Answer_Key.txt.
- Run_Log.txt: the log of every step and every check.

What the laptop needs:
- Excel (2016 or later) and Windows PowerShell, which every company laptop has.
- Python 3 with its standard library only, no package. If it is missing, the tool says so and stops.

If the tool stops: read the last lines on the screen or in Output\Run_Log.txt. They give the file, the row and the reason.
The documentation is in the docs folder: SKILL.md (the skill for Claude Code), HISTORY.md (how the tool was built)
and LESSONS.md (the lessons learned).
